# Real-World Finance Data Project
**Thiranex Internship Assignment**

## 📌 Project Overview
This repository contains a simple financial trend tracking and machine learning application. It profiles baseline stock fluctuations, prepares data windows, and uses a Linear Regression engine to evaluate directional market behavior.

## 🚀 Key Framework Architecture
* **Self-Contained Pipeline**: Includes a built-in financial stream—no `.csv` data setups needed.
* **Basic Analytics**: Evaluates central statistics and performance tracking directly.
* **Prediction Model**: Features a Scikit-Learn regression block predicting values from historical records.
